1) номер запчасти начинается с букв, а в поиске вводят без букв
2) детали идут с разделителями, а пользователь вводит слитно
3) интернациональные буквы
4) Релевантность первого слова в названии, то это важнее чем в середине и в конце
5) Релевантность первого слова в каталожном номере важнее

| Проблема                                                               | как решать                                                                                                               | Решили |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------ |
| номер запчасти начинается с букв, а в поиске вводят без букв           | Добавить индекс поле с удалением всех букв                                                                               |        |
| детали идут с разделителями, а пользователь вводит слитно              | Добавить в индекс значение слитно<br>Добавить в индекс слитно без букв                                                   |        |
| интернациональные буквы в катномерах<br>                               | К полям связанным с каталожным номером добавляем анализатор индекса и анализатор поиска в заменой интернациональных букв |        |
| разные разделители слов в каталожном номере в запросе и в детали       | позаботиться чтобы в анализаторах были все символы-разделители слов                                                      |        |
| Номер начинают вводить не с начала                                     | Использовать обработчик разделитель слов                                                                                 |        |
| Релевантность первого слова в названии важнее чем в середине и в конце | Добавляем в индекс поля с обрезанными первыми словами и с первыми двумя, и делаем для них буст                           |        |
| Релевантность первого слова в каталожном номере важнее                 | Добавляем индекс только с первым словом                                                                                  |        |
