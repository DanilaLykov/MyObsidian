Категории веток:

1) **master** предназначена для боевого использования. Каждый камит в ней помечается тегом (версия).
2) hotfix - группа веток вида hotfix/проблема. Предназначена для горячих правок. 
3) dev - Одна ветка, предназначена для проверки работы новых функции и объединения работы нескольких разработчиков. В нее мержатся все готовые функции и фиксы.
4) features - группа веток предназначенная для разработки новых функий.



Пример:

Сергею поставили задачу по редизайну админсокй темы, а так же админской панели, которая выводится на лицевой стороне сайта. 

Так вышло, что в рамках этой работы было принято решение использовать для массовых операций более продвинутый модуль VBO, что подразумевало включение нового модуля, и переконфигурацию вьюсов, предоставленных другими контрибными модулями.
