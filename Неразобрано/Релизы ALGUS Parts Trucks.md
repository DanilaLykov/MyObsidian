Релиз тракс

1) Поиск еластиксерч
		Установка и настройка ПО сервера ElasticSearch
		Обработка запросов интерактивного поиска и на странице поиска через еластиксерч
		Реализация возможности настраивать коэффициенты для полей
		поиск по категориям, подборкам, единицам
2) Подборки еластиксерч
		подборки с возможностью добавлять поисковое слово, как одну из характеристик
		автоматический переход с обычных подборок на es_product_collection
		страница простейшей подборки
3) Модуль расширяющий возможности вывода характеристик at_advanced_params
		Реализация возможности использования одновременно нескольких вариантов отображения поля кратких характеристик  (Авто-Таблица, Авто-список)
		Возможность выбора одного из нескольких видов отображения характеристик в карточке и в тизере
		Новый вид отображения характеристик в сгруппированной таблице
		Для изменения вывода отображения характеристик теперь не требуется пересохранять ноды
4) Форматы вывода категорий и подкатегорий
		Вывод категорий и подкатегорий происходит в 6 видах:
			теги
			список
			двухуровневый список
			плитка
			плитка расширенная
			плитка мини
		

Релиз партс

1) Модуль интеграции запчастей с авито
		Фид для загрузки товаров на авито
		Настройки фида с помощью фильтровых параметров (в наличии, с картинкой и т.д.)
		Дополнительные поля у категорий, для ввода разделов на авито
2) Вывод страницы раздела через макет
		Добавление блоков для вывода на странице раздела
		Возможность выводить разный контент в каждом разделе
		Редактирование вывода раздела с помощью визуального интерфейса
3) Интеграция с сервисом доставки (проверить уровень готовности)
4) Поиск еластиксерч
		Установка сервера еластиксерч
		Обработка запросов интерактивного поиска и на странице поиска через еластиксерч

Релиз Дата-партс

1) Форматтеры картинок для картинок с дп
		При выводе картинок через форматтер, происходит проверка настроек приоритета
		Четыре форматтера для вывода картинок:
			Галерея
			Галерея с превью
			Галерея в тизере
			Вывод первой картинки
		Вывод заглушки через общий шаблон
2) Заголовки с датапартс в alt и title картинок
3) Визуальные каталоги 
		4 версия API
		Увеличение базы для визуальных каталогов
