Программный модуль для Drupal, предоставляющий возможность организовать чат на сайте, причем общение может быть связано с каким либо материалом, либо другой сущностью. Так же модуль предоставляем организовать чат со службой поддержки.

Модуль предназначен для установки на сайты gruzovik.biz и partizon.ru

## Технологии

- REST API ([[Описание методов REST API chat]]) 
- Websocket библиотека PHP Rachet ([[Описание WebSocket API чата]])
- База данных
- React JS для верстки виджета чата и страницы в админке

## Дизайн 

Компоновку мы позаимствовали у Авито, оформление сделано в общем стиле сайта.
