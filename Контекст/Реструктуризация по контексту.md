
## Цели и методы

Цели:

- Улучшение качества обслуживания
- Ускорение процесса обслуживания и разработки
- Снижение нагрузки на Инну
- Увеличение доходов 


Увеличение доходов:

- Тарифы на обслуживание
- Увеличение бюджетов на пополнение

Улучшение качества:

- Общение с клиентами
- Ведение логов изменений в рекламе
- Более информативные отчеты
- Список проведенных работ в отчете
- Проведение большего количества работ по обслуживанию

Ускорение процесса:
- Механизм слежки за 404 страницами


## План действий

- Определить несколько тарифов на обслуживание
	- Описать перечень работ и время
	- Выписать рекламные продукты подходящие для тарифов
	- Описание стратегий, которые можем использовать
- Большую часть клиентов списываем на тариф "Пополнение"
- Всех клиентов разложить по рекомендуемым тарифам
- Определяем объем работ по типам в месяц
- Распределить работы по исполнителям
- Определить перечень необходимых регламентов по работам


Переход на новую схему

- Подготовить новые договоры
- Перевести клиентов


Действия:

- Инне - подумать над перечнем обязательных работ для тарифа пополнение
- Мне Автоматизацией проверки адресов страниц рекламируемых
