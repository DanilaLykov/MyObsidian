Указание категорий задачам происходит с помощью пользовательского поля в задаче "Категория задачи", котором текстом должно быть написано машинное имя категории (только одно и ничего более).  

### Требования к платным задачам:

- Задача должна быть привязана к сделке
- Должны быть проведены расчеты по задаче (для всех сотрудников в задаче, которые отмечали время в задаче должно быть указано проданное время)
- Сумма времени по задаче должна быть равна расчетной сумме времени 

### Требования к задачам для нашей конторы

- Задача должна быть привязана к одному из наших проектов
- Должны быть проведены расчеты по задаче (для всех сотрудников в задаче, которые отмечали время в задаче должно быть указано проданное время)
- Сумма времени по задаче должна быть равна расчетной сумме времени
