
Необходимо написать парсеры в Jupyter Notebook собирающие информацию по запасным частям с сайтов. 

В ноутбуке желательно все разбить по этапам сбора разной информации, например сначала собираем Урлы разделов, потом урлы запчастей, потом парсим страницы деталей. 

Данные по каждому сайту должны быть в отдельном файле CSV типа shop-kamaz-ru.csv

Столбцы файла парсинга:

- cat_number (какталожный номер детали в то виде как он есть)
- synonyms (через запятую альтернативные каталожные номера)
- title (название детали, без каталожного номера)
- brand (производитель в том виде как указан у продавца, не путать с маркой машины)
- category (раздел каталога в виде "Двигатель>>подвеска двигателя" если сложно, то можно не брать)
- lenght (длина в метрах в виде 0.51)
- width (ширина в метрах в виде 0.51)
- height (высота в метрах в виде 0.51)
- weight (вес в килограммах в виде 45.35)
- sertificat (сертификат в виде url файла https://www.autoopt.ru/product_certs/0034068645/0b.pdf)
