
Для пополнения базы данных запчастей в сервисе data-parts.ru мы проводим фотографирование складов запасных частей и дальнейшую обработку и выгрузку на сервер. 

Зачастую фотосессии проводятся на условиях:
- Клиент предоставляет склад запчастей для фотографирования
- Мы фотографируем запчасти (бесплатно), и предоставляем клиенту лицензию на использование фотографий для своей деятельности
- Исключительные права на фотографии остаются в нашей компании

## Порядок работ:

### 1.  Проведение фотосессий и выгрузка в облако

После согласования с складом всех условий проведения фотосессий, фотограф выезжает на склад, устанавливает оборудование и проводит одну или несколько фотосессий по иснтрукции. [[Инструкция для фотографа по съёмке запчастей]]


### 2. Предоставление копий фотографий для клиента

На этом этапе создается папка для клиента, в которую попадают фотографии в той-же структуре папок и имен файлов, что и в папке загрузки, но с уменьшением размера изображений до 3000 px по длинной стороне. 
### 3. Обработка фотосессий

Новые партии фотосессий переносятся в папку обработки и в ней проводится работа по объединению фотографий в папки деталей, и папки фотогалерей по инструкции. [[Обработка фотографий для data-parts.ru]]

### 4. Подготовка к загрузке и загрузка на сервер

Обработанные фотографии переносятся в папку готовых фотографий, предназначенную для загрузки на сервер, и оттуда загружаются на сервер. [[Подготовка фотографий к загрузке]]

### 5. Обновление информационных данных по источникам

Запускается специальный скрипт через драш-команду, который обновляет базу данных по источникам данных.

## Описание папок

#### КЛИЕНТ-Загрузка

Папка предназначена для загрузки фотографий после каждой фотосессии фотографом. Он создает папку с датой выгрузки фотосессии и выгружает туда все содержимое фотосессии не меняя имен файлов. 

#### КЛИЕНТ-Клиенту

Папка предназначена для предоставления доступа к фотографиям, сделанным на складе клиента клиенту. В нее мы складываем фотографии в том же пордке и структуре папок и имен файлов, но с предварительным уменьшением размера изображения и удалением метаданных, чтобы оригиналы фотографий были только у нас. 

#### КЛИЕНТ-Обработка

Папка предназначена для проведения обработки фотографий (раскладка по деталям и фотогалереям). Изначально туда попадают копии папок новых фотосессий из "КЛИЕНТ-Клиенту" А потом поэтапно проходит обработка фотографий, после каждого этапа к именам папок добавляется #  в начало имени. 

#### КЛИЕНТ-Готово

Здесь сложены фотографии в структуре, готовой для загрузки на сервер data-parts.ru по клиенту. По мере окончания обработки эта папка пополняется фотографиями и папки "КЛИЕНТ-Обработка".
