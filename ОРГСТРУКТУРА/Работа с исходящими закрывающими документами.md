
## Создание сущностей Бухдоков

После завершения работ по сделке (или при наступлении даты окончания сделки) запускается бизнес процесс по созданию сущности Бухдока (вручную либо автоматически), в результате должен появляется элемент Бухдок на стадии "Не сформирован", который дублирует все данные из связанных сущностей (сделка, счет, платеж), он является заданием бухгалтеру на формирование документа в 1С. 

Перед созданием Бухдоков, менеджер должен убедиться что все поля сделки и счета заполнены правильно. 

## 1.  Не сформирован. Формирование документов

Бухгалтер должен:
- сформировать соотв. документы в 1С;
- сохранить в формате PDF, имя файла должно содержать тип, номер закрывающего документа,  название контрагента и дату документа (пример: УПД 345 Энергомаш 30.09.2026.pdf);
- прикрепить файл PDF к соотв. Бухдоку;
- перенести стадию Бухдока на "Сформирован".

## 2. Сформирован. Проверка закрывающих документов PDF

Менеджер проверяет все документы PDF, на соответствие их Бухдокам, используя специальный инструмент для сверки. 

При выявлении несоответствий менеджер пишет задание бухгалтеру на переделку документа (дело в ленте бухдока). Бухгалтер должен исправить, и прикрепить правильный документ, и отметить задание на исправление выполненным. 

Менеджер повторно проверяет документ. 

Документы прошедшие проверку Менеджер переносит на стадию "Проверен". 

## 3. Проверен. Отправка клиенту

На данном этапе мы отправляем документы клиентам тем способом, который для них подходит (бумага или ЭДО). 

Для документов, которые отправляются в бумажном виде, Менеджер должен распечатать PDF (в 2 экземплярах), подписать, отсканировать, правильно назвать сканы (Скан УПД 515 Энергомаш Оптимизация 09.2026.PDF) и отправить скан по почте клиенту и положить бумажный документ в лоток "Клиентам". 

Для документов, которые должны отправляться по ЭДО, Бухгалтер должен отправить по ЭДО в 1С. 

Все Бухдоки по отправленным документам (в виде сканов и по ЭДО) необходимо перенести на стадию "Отправлен клиенту" тем, кто производил отправку (по ЭДО - Бухгалтер, по сканам - Менеджер). 


## 4. Отправлен клиенту. Получение подписанных доков. 

На этой стадии мы отслеживаем все подписание документов клиентам, и после получения подписанного экземпляра (бумажного, или по ЭДО) переносим документ на стадию "Подписан клиентом". 

Бухдоки по документам, подписанным по ЭДО на стадию "Подписан" переносит Бухгалтер, 




Бухгалтеру:
- Сформировать УПД по заданию из бизнес-процесса
- Подписать и отправить УПД по ЭДО

Менеджеру:
- Распечатать документы, требующие отправки в бумажном виде
- Подписать документы
- Отсканировать документы и отправить клиентам по почте
- Сложить подписанные документы в папку для клиентов
