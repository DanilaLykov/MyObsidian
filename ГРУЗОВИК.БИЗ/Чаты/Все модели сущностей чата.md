5. send_message

	Отправляет:
	```json
		{
		 "type": "send_message", 
		 "data": 
			 { 
			 "content": "Текст сообщения", 
			 "author_uid": 4, 
			 "chat_id": 45 
			 } 
		}
	```
	Получает:
	```json
	{ "type": "send_message", 
		"data": 
		{ 
			"id": 220, 
			"text": "hellomir", 
			"author_uid": 1, 
			"created": "2023-07-17 15:47:30", 
			"chat_id": 215, 
			"status": 1 
		}
	}
	```
