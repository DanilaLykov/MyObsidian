
При построении страниц сайта проходит несколько этапов.

1) Определение типа страницы по пути
   path - метод получает url (без гет параметров), фозвращает структурированный массив с типом сущности, бандлом, id сущности и id_geo, url без гео, редирект
2) Определяем шаблон страницы по типу сущности
3) Запрашиваем данные по соотв. сущности через соотв. метод
4) Запрашиваем данные для дополнительных блоков
