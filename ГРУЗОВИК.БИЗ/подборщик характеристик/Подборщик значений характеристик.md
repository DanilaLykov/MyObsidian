Микросервис, возвращающий перечень возможных значений запрашиваемого параметра техники, в порядке вероятности подходимости к заполняемому объявлению, на основе известных значений категории техники, марки-модели и других параметров. 


**get_param_values** 

Метод возвращает перечень возможных значений в порядке вероятности применимости. 

Принимает:
- category_id
- mark_id
- model_id
- params (массив пар параметр-значение)

Возвращает:

```json
{
	'result': ["значение1", "значение2","значение3"]
}
```

```json
{
	'result': false,
	'error': "Текст ошибки"
}
```


### Таблицы, в которых хранятся данные, необходимые возврата статистики

**properties** 
таблица EAV с параметрами объявлений.
entity_id - айди объявления


**node__field_technic_catalog** 
Таблица в которой хранятся связи объявлений и разделов каталога. 
entity_id - айди объявления
field_technic_catalog_target_id - айди категории техники

**node_revision__field_mark**
Таблица связи марок и объявлений
entity_id - айди объявления
field_mark_target_id - айди марки

**node_revision__field_model**
Таблица связи моделей и объявлений
entity_id - айди объявления
field_model_target_id - айди модели
