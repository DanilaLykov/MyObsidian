
# Отправление статистики

Отправляем с фронта прямо в FastAPI

POST /api/v1/insert

```
{
	"events": 
	[
		{
			item_id: "265186", 
			metric: "view", 
			owner_ad: "1588"
		}
		
	]
}
```

или батч

POST /api/v1/insert

```
{
	"events":
	[
		{
			item_id: "265186", 
			metric: "show", 
			owner_ad: "1026"
		},
		{
			item_id: "265655", 
			metric: "show", 
			owner_ad: "2024"
		},
	]
}
```



Значения добавляем на:

|             | На фронте | В FastAPI |
| ----------- | --------- | --------- |
| id          |           |           |
| id_ad       | +         |           |
| client      | ??        | ??        |
| time        | +         |           |
| ip          |           | +         |
| useragent   |           | +         |
| owner_ad    | +         |           |
| description |           |           |
| type        | +         |           |
