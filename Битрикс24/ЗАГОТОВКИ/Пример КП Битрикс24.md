Перечень работ по Базовому внедрению CRM «Битрикс24»  
  
1.    Создание портала и общие настройки:  
	- Регистрация корпоративного портала Битрикс24  
	- Создание учетных записей для всех сотрудников (до 10)  
	- Создание структуры компании   
  
2. Электронная почта:  
	- Привязка почтовых ящиков сотрудников к порталу  
	- Привязка общего ящика компании к порталу  
	- Настройка распределения доступа к письмам  
	- Настройка подписей к письмам  
  
3.  IP Телефония:  
	- Интеграция виртуальной АТС c Битрикс24 (1 линия)  
	- Настройка исходящих звонков  
	- Настройка распределения входящих звонков  
	- Создание аккаунтов телефонии для сотрудников  
	- Инструкция по настройке IP-телефонов  
	
4. Настройка CRM:  
	- Настройка карточек Компаний, Контактов, Сделок  
	- Настройка стадий сделок (1 воронка)  
	- Упрощенная настройка прав (менеджеры и руководитель)
	- Настройка сфер деятельности контрагентов 
  
5. Обучение и инструкции:  
	- Инструкции по работе с CRM для менеджеров  
	- Обучение 3 часа (онлайн/офлайн)  
	- Поддержка в течение 30 дней (помощь )
